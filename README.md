# TECHCORE AI / PanelLab

정적 웹사이트(HTML·CSS·JavaScript, 빌드 도구 없음)로 구성된 두 개의 화면 묶음입니다.

- `techcore/` : TECHCORE AI. 단순한 시작 화면에서 AI 채팅(AGENT01 대상으로 설계, 대상 확인은 **미확인**)과 작업 화면으로 이동합니다.
- `panellab/` : PanelLab. Mitsubishi PLC 래더와 HMI를 다루는 기존 작업실입니다. TECHCORE AI는 이를 변경하지 않고 열기만 합니다.

## 실행 방법
빌드가 없습니다. 저장소 루트를 정적 서버로 제공하고 `/techcore/` 또는 `/panellab/`을 엽니다. (예: GitHub Pages)
`file://`로 열면 채팅 연결용 서버가 요청을 거부하므로 채팅은 동작하지 않습니다.

## 폴더 구조
```
techcore/            TECHCORE AI
  index.html, css/techcore.css
  js/app.js          라우터와 화면
  js/registry.js     분야·상태 데이터(전문가 목록 포함)
  js/workflow.js     데이터 전달 10단계 표시(표시 전용)
  js/results.js      통합 결과실 표시(표시 전용)
  js/intake.js       시작 화면 질문 흐름(메모리 상태, 전송은 기존 bridge 이용)
  js/ledger.js       호출 기록·검증 단계(L1~L5)
  js/chat.js, bridge.js  채팅 연결과 PanelLab 연동(이번 작업에서 변경하지 않음)
panellab/            PanelLab (이번 작업에서 변경하지 않음)
docs/                agent-guide.md, test-cases.md
```

## 데이터 저장과 보안 한계
- 기록은 브라우저 `localStorage`에만 저장되며 기기 간 공유되지 않습니다.
- 대화 기록(`techcore.transcript.v1`)은 사용자 메시지가 발생한 대화부터 사용자·AI 메시지를 저장하며, 대화 ID(`activity.id`)가 같은 메시지는 중복 기록하지 않습니다(ID가 없는 활동은 중복 방지 대상이 아님). 서버에 저장되는 기능은 없습니다.
- 저장 한도(20대화·300메시지·대화당 텍스트 4000자·전체 약 70만 자)를 넘으면 오래된 대화부터, 필요하면 현재 대화의 오래된 메시지도 정리하고 최신 메시지를 최대한 보존합니다. 한 대화가 300개를 넘어 삭제된 메시지도 정리 수에 합산되며 설정 화면에 표시됩니다. 이 정리 수는 화면을 새로고침하면 0으로 돌아갑니다(저장하지 않음, UNVERIFIED 동작이며 저장하려면 새 저장 구조가 필요해 이번에는 제안만 합니다).
- 기존 기록이 손상되었거나 버전이 다르면 `techcore.transcript.v1.bak`에 백업한 뒤 교체합니다. 이미 다른 백업이 있으면 `techcore.transcript.v1.bak.<시각>` 키를 씁니다. 백업에 실패하면 기존 데이터를 그대로 두고 저장을 중단합니다.
- 기록 시각은 유효한 activity `timestamp`를 우선 사용하고, 없거나 유효하지 않으면 현재 시각을 사용합니다. 기존 저장 형식은 그대로입니다.
- 설정의 기록 내려받기(텍스트)는 다운로드 후 Object URL을 해제합니다. 기록 모듈에 오류가 있어도 설정의 다른 기능은 동작하도록 해당 영역만 안내를 표시합니다.
- 캐시 버전: `app.js?v=41`, `techcore.css?v=28`, `transcript.js?v=5`. 배포된 브라우저에서 새 코드가 로드되는지는 **미검증**(UNVERIFIED)입니다.
- 시작 화면 질문의 답변은 메모리에만 있고 저장하지 않습니다. 새로고침하면 사라집니다.
- 사이드바 접힘 여부(`sideCollapsed`)는 `techcore.v1`에 함께 저장됩니다. 저장값이 없으면 화면 폭으로 정합니다.
- AGENT01 연결은 접속 시나 채팅 화면 진입 시 자동으로 하지 않습니다. 사용자가 [채팅 시작]을 누르거나 메시지를 보낼 때만 연결합니다(실제 브라우저 확인은 UNVERIFIED).
- 정적 JavaScript에 포함된 데이터(전문가 목록 등)는 브라우저 개발자 도구로 누구나 확인할 수 있습니다. 화면에서 숨기는 것은 보안 수단이 아닙니다.
- 채팅 연결 설정은 브라우저 코드에 포함되어 있습니다. 보호 수준과 정책은 확인하지 않았습니다.
- PanelLab 화면을 열면(TECHCORE에 내장해 여는 경우 포함) `panellab/index.html` 143행이 Bot Framework WebChat 스크립트(4.18.0)를 CDN(`cdn.botframework.com`)에서 읽습니다(무결성 검사 SRI 있음). 채팅 서버(Broker)나 토큰을 요청하는 것은 아닙니다. 따라서 "화면 진입 시 외부 요청이 없다"고 볼 수 없습니다. 이 요청이 실제로 일어나는지는 코드를 읽어 확인했고 브라우저 네트워크 탭에서는 **미검증**입니다.
