# TECHCORE AI / PanelLab

정적 웹사이트(HTML·CSS·JavaScript, 빌드 도구·패키지 없음)입니다. GitHub Pages(main 루트)로 배포합니다.

- `techcore/` : **TECHCORE AI**. 질문을 적고 AI 채팅(AGENT01 대상으로 설계, 대상 확인은 **미확인**)으로 보내는 쉬운 시작 화면과 작업 화면입니다.
- `panellab/` : **PanelLab**. Mitsubishi PLC 래더와 HMI를 다루는 기존 작업실입니다. TECHCORE AI는 이를 변경하지 않고 열기만 합니다.

배포 주소: https://kmkspu36.github.io/plcplcplcplc/techcore/

> 표기 규칙: **미확인 / 미검증(UNVERIFIED)** = 코드는 읽었지만 실제 동작을 확인하지 못함. **구현** = 코드가 들어가 있음(확인 범위는 같은 줄에 적음). "코드를 읽었다"와 "동작을 확인했다"는 구분해서 적습니다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 홈 | "무엇을 도와드릴까요?" 입력창 + 예시 질문 4개(누르면 입력창에만 채움, 자동 전송 아님) + 용어 줄(PLC·HMI·래더) + 단계별 질문 시작 |
| AI 작업실 | AGENT01 통합 채팅. [채팅 시작]을 누르거나 메시지를 보낼 때만 연결 |
| PanelLab | 기존 PLC·HMI 작업실(변경 없음) |
| 보조 화면 | 내 작업(프로젝트·휴지통·백업), 도움말, 설정, 소개. 메인 사이드바에는 위 3개만 둠 |

- 사이드바는 접기/펼치기, 접힌 상태에서는 툴팁으로 메뉴명을 보여 줍니다(≥1200px 기본 펼침, 901~1199px 기본 접힘).
- 홈에는 분야 카드가 없습니다(6단계-K). 분야 작업실(PLC·HMI, 전기·전자, 데이터 전달 관리)은 채팅 화면의 "분야 변경" 선택이나 주소(`#/field/plc-hmi`, `#/field/electric`, `#/transfer`)로 들어갑니다. 라우팅·분야 코드는 그대로 보존합니다.
- 오른쪽 정보 패널은 기본 숨김입니다(설정의 "상세 정보 패널(고급)"으로만 표시).

## 실행 방법

빌드가 없습니다. 저장소 루트를 정적 서버로 제공하고 `/techcore/` 또는 `/panellab/`을 엽니다. 예: `python -m http.server 8765` 후 `http://localhost:8765/techcore/`

`file://`로 열면 채팅 연결용 서버가 요청을 거부하므로 채팅은 동작하지 않습니다.

개발용 점검 페이지: `/tests/transcript-check.html` 을 열고 [점검 시작]. 가짜 채팅으로 대화 기록·저장 로직 12개 항목을 확인합니다(AGENT01 연결·네트워크 요청 없음, 점검 뒤 저장값 원복). 주소 끝에 `?run=1`을 붙이면 자동 실행합니다.

## 데이터 저장과 보안 한계

- 기록은 브라우저 `localStorage`에만 저장되며 기기 간 공유되지 않습니다. 브라우저 데이터를 지우면 사라집니다. 서버에 저장되는 기능은 없습니다.
- 사용하는 저장 키: `techcore.v1`, `panellab.v1`, `techcore.projects.v1`, `techcore.trash.v1`, `techcore.ledger.v1`, `techcore.field.electric.v1`, `techcore.transcript.v1`(+`.bak`), `panellab.ui.v1`, 그리고 sessionStorage `techcore.draft.v1`(입력 초안).
- 대화 기록은 사용자 메시지가 발생한 대화부터 저장합니다. 첫 사용자 메시지 전의 환영 메시지는 저장하지 않습니다. 같은 `activity.id`의 메시지는 중복 기록하지 않습니다(ID 없는 활동은 대상 아님).
- 한도(20대화·300메시지·대화당 텍스트 4000자·전체 약 70만 자)를 넘으면 오래된 대화부터, 필요하면 현재 대화의 오래된 메시지도 정리합니다. 정리 수는 새로고침하면 0으로 돌아갑니다(저장하지 않음).
- 기존 기록이 손상되었거나 버전이 다르면 `techcore.transcript.v1.bak`(이미 있으면 `.bak.<시각>`)에 백업한 뒤 교체합니다. 백업에 실패하면 기존 데이터를 두고 저장을 중단합니다.
- 복원이 성공하면 새로고침 전까지 저장을 일부러 중단합니다(화면의 옛 값이 복원된 값을 덮어쓰지 않게 하기 위함).
- 시작 화면 질문의 답변은 메모리에만 있고 새로고침하면 사라집니다.
- 사이드바 접힘 여부(`sideCollapsed`)는 `techcore.v1`에 함께 저장됩니다.
- 캐시 버전: `app.js?v=44`, `techcore.css?v=29`, `transcript.js?v=6`, `help.js?v=4`, `electric-ui.js?v=2`. 배포 브라우저에서 새 코드가 로드되는지는 **미검증**입니다(Ctrl+F5 후 개발자 도구 Network 탭에서 확인).
- AGENT01 연결은 접속 시나 채팅 화면 진입 시 자동으로 하지 않습니다. 사용자가 [채팅 시작]을 누르거나 메시지를 보낼 때만 연결합니다. 코드에는 자동 연결 경로가 없지만, 한 번 클릭 없이 "AGENT01 연결 중"이 보였다는 보고가 있어 원인은 **미확인**입니다(시크릿 창에서 `#/workroom`을 열고 10초 뒤 Network 탭에 `directline` 요청이 있는지 확인).
- 정적 JavaScript에 포함된 데이터(전문가 목록 등)는 개발자 도구로 누구나 볼 수 있습니다. 화면에서 숨기는 것은 보안 수단이 아닙니다.
- 채팅 연결 설정은 브라우저 코드에 포함되어 있습니다. 보호 수준과 정책은 확인하지 않았습니다.
- PanelLab 화면을 열면(TECHCORE에 내장해 여는 경우 포함) `panellab/index.html`이 Bot Framework WebChat 스크립트(4.18.0, SRI 있음)를 CDN(`cdn.botframework.com`)에서 읽습니다. 채팅 서버나 토큰을 요청하는 것은 아니지만 "화면 진입 시 외부 요청이 없다"고 볼 수는 없습니다. 실제 요청은 Network 탭에서 **미검증**입니다.
