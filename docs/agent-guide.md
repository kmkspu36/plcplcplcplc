# 에이전트 안내

> 이 문서는 Copilot Studio의 실제 지침과 설정을 확인하지 않고 작성했습니다. 확인되지 않은 항목은 "미확인"입니다.

## 사용 원칙
- 사용자는 AGENT01(으로 설계된 채팅)에게만 요청합니다. 전문 에이전트를 직접 고르지 않습니다.
- 현재 채팅 대상은 "AI Creative Agent"이며 AGENT01인지는 **미확인**입니다.
